========================================
CONFIGURACIÓN DE GOOGLE ANALYTICS
========================================

PASO 1: Crear cuenta de Google Analytics
-----------------------------------------
1. Ve a https://analytics.google.com/
2. Inicia sesión con tu cuenta de Google
3. Haz clic en "Comenzar a medir"
4. Completa la configuración de la cuenta:
   - Nombre de cuenta: "Portfolio Nahuel Obregón"
   - Configuración de la propiedad
   - Nombre de la propiedad: "Portfolio Website"
   - Zona horaria: Argentina (GMT-3)
   - Moneda: Peso argentino (ARS)

PASO 2: Configurar flujo de datos
----------------------------------
1. Selecciona "Web" como plataforma
2. URL del sitio web: https://tudominio.com
3. Nombre del flujo: "Portfolio Production"
4. Copia el ID de medición (formato: G-XXXXXXXXXX)

PASO 3: Reemplazar en index.html
---------------------------------
1. Abre: cliente/index.html
2. Busca: G-XXXXXXXXXX (aparece 2 veces)
3. Reemplaza con tu ID de medición real

Ejemplo:
<!-- Antes -->
gtag('config', 'G-XXXXXXXXXX');

<!-- Después -->
gtag('config', 'G-1A2B3C4D5E');

PASO 4: Verificar instalación
------------------------------
1. Deploy tu sitio
2. Ve a Google Analytics > Informes > Tiempo real
3. Abre tu sitio web en otra pestaña
4. Deberías ver tu visita en "Usuarios en tiempo real"

EVENTOS PERSONALIZADOS (Opcional - Avanzado)
---------------------------------------------
Si quieres trackear eventos específicos, puedes agregar:

// En cualquier componente React:
const trackEvent = (eventName, params = {}) => {
  if (window.gtag) {
    window.gtag('event', eventName, params);
  }
};

// Ejemplo de uso:
// Al descargar CV
trackEvent('download_cv', {
  file_name: 'CV_Nahuel_Obregon.pdf'
});

// Al enviar formulario de contacto
trackEvent('contact_form_submit', {
  form_name: 'contact_form'
});

// Al ver un proyecto
trackEvent('project_view', {
  project_name: 'GameXperience'
});

MÉTRICAS A MONITOREAR
----------------------
Una vez configurado, podrás ver:
✅ Número de visitantes únicos
✅ Páginas más visitadas
✅ Tiempo promedio en el sitio
✅ Tasa de rebote
✅ Ubicación geográfica de visitantes
✅ Dispositivos utilizados (móvil/escritorio)
✅ Fuentes de tráfico (directo, búsqueda, redes sociales)
